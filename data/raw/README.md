# Raw data

Raw clinical datasets are not redistributed in this repository.

## Adult Appendicitis

The Adult Appendicitis dataset is publicly available from:

https://www.kaggle.com/datasets/timrie/appendicitis

The analysis-ready dataset used by the released scripts is provided in:

`data/derived/adult_selected_cleaned_data.csv`

## Regensburg Pediatric Appendicitis (RPA)

The RPA dataset is publicly available from Zenodo:

https://zenodo.org/records/7669442

The analysis-ready RPA dataset and derived simulation parameters are provided in:

`data/derived/`

## Düsseldorf external-validation dataset

The independent Düsseldorf pediatric appendicitis dataset is publicly available from:

https://github.com/i6092467/pediatric-appendicitis-ml-ext

Download the file:

`app_data_ext.csv`

and place it in this directory as:

`data/raw/app_data_ext.csv`

The raw Düsseldorf dataset is not redistributed here.
